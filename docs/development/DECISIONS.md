# 技术决策

- 2026-10-09：采用用户批准的Tauri/React/FastAPI/Docling/SQLite架构。根据真实包注册表、Windows轮子与解析烟测锁定版本，调研所得版本不能代替安装验证。
- PDFium用于渲染及裁剪，保留其二进制第三方许可。数字原生PDF为首版重点，OCR限制明确显示。
- 默认一个解析子进程。解析子进程不写数据库，父进程校验并发布结果。
- 搜索汉字按字分词，拉丁词保留，使用FTS5短语查询；用户输入不作为FTS语法执行。
- 新代码保留所有权利。第三方代码、模型、测试论文各自保留原许可证。仅做本地交付，不自动发布远程仓库。
- 真实Sidecar验收中，Windows multiprocessing spawn与带stdin控制管道的启动组合出现worker初始化停滞；独立解析与dev模式正常。任务改用显式同一EXE的`--worker`子进程及JSONL进度，stdin为DEVNULL，保留独立进程取消/超时/崩溃隔离。该方案也减少冻结环境对multiprocessing序列化引导的依赖。

## 0.2 阅读工作台

- 阅读状态和可定位笔记使用独立数据库表，不混入自动解析资源或原有个人备注。重解析可以替换自动结果而不改动用户阅读记录；导出包含来源PDF哈希、页码与原始坐标。
- 迁移0002先用SQLite Backup API备份，DDL显式置于事务；失败回滚后仍可从0001重试。旧版回退使用升级前完整备份，不能直接打开升级后的数据库。
- 每条修改携带预期版本，409保留草稿并由用户选择；客户端库身份同时包含UUID和实际目录，避免恢复副本保留UUID后串用旧状态。库切换和写请求在异步锁内核对身份。
- 阅读自动保存使用串行合并队列；导航与原生关闭先处理当前草稿和待发送状态。队列只在保存状态、错误、冲突或阅读状态变化时更新父界面，滚动位置由PDF阅读器管理，避免每个滚动像素重绘全部标注。
- 每次标注快照预先按页分组；页面和覆盖层复用未变内容，离屏移除标注覆盖层与画布，已访问页文字层保留以支持跨页选择。单页位图预算不作为整个WebView进程内存保证。
- 安装验收使用真实0001库、固定WebView2用户目录和实际键盘输入。浏览器组件测试、真实本地API、冻结后端与安装后Tauri分别记录，合成压力数据不计算解析准确率。
