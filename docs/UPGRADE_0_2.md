# 0.2 阅读工作台升级与验收

用户目标：全面升级功能、交互和 UI，运行时间不少于 5 小时。前一轮 0.1.1 的界面精简不代表这一目标已完成。本轮从实际工作树 `6fee878` 继续，完成要求同时证明功能与时长；最终结果见本文件末尾。

## 工作流

围绕“打开论文 → 连续阅读 → 标注/记录 → 跨论文查找 → 返回原文 → 导出复用”完整升级。保持本地运行、原 PDF 不变、用户数据可备份恢复和克制的桌面界面。P2 云同步、语义检索和高级 OCR 不在本轮范围。

## 完成门槛

1. **连续阅读**：按论文持久化页码/页内位置、缩放、旋转与适配模式；再次打开恢复，显式定位优先。支持未读/在读/已读状态、最近阅读入口，切换库后不串用状态。
2. **可追溯笔记**：页书签、文本高亮和区域笔记，保留原文引用、页码与未旋转 PDF 坐标；支持修改、标签/颜色、删除与撤销。文本选择跨行/跨页有明确行为，不将整个段落错误涂满。重新解析不覆盖用户记录。
3. **笔记组织**：论文详情笔记面板和全库笔记列表，搜索、按论文/类型/标签筛选、分页、原文定位；Markdown/JSON 导出包含来源和位置，保存取消不报告成功。
4. **阅读交互**：多论文标签页、返回/前进、会话恢复；可调宽度/可收起信息栏；适合宽度/整页、页内查找及键盘操作。搜索/图库跳转仍准确，Ctrl+K 原有全局搜索入口保留。
5. **修改保护**：论文信息、目录、资源与笔记的未保存编辑在关闭/切换时可保存、放弃或继续编辑；保存失败不能静默丢稿。切库和原生窗口关闭纳入验证。
6. **数据与升级**：旧库有迁移前备份，新增记录按事务保存，位置/长度/范围校验，移除论文后其笔记不泄漏到全库结果；备份恢复、并发编辑冲突、重启、重解析与异常写入可验证。
7. **UI**：使用 0.1.1 中性灰主题与紧凑工具栏；不新增口号或装饰大卡。状态、空态、失败/重试、键盘焦点可用；亮/暗主题、1280×800 及高 DPI 下实测。
8. **交付**：后端、前端及实际 PDF 交互测试通过；冻结后端与 Windows 安装包包含新功能；真实安装后升级旧库/阅读/笔记/定位/导出/恢复验收；更新使用指南、数据格式、架构、依赖/许可证记录及已知限制，提交源码与证据。
9. **时长**：依据 active goal 的 `createdAt`、`timeUsedSeconds` 及工具 UTC 时间记录，不以空转、重复无关测试或单纯等待凑时长。累计不足 18,000 秒时不能标记完成；各阶段继续实施与验收，不缩小范围来满足已有测试。
